- **REQUIRES MANUAL ACTION:** select only categories that describe services actually offered; add complete service descriptions without unsupported outcomes or guarantees.
- **REQUIRES MANUAL ACTION:** publish genuine, permissioned team/work photos; request and respond to authentic reviews.
